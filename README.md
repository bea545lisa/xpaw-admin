# RexPaw Admin

Advanced Shopify product management application built with Remix, Polaris and Shopify Admin API.

## Features

- Bulk product editing
- Variant management
- Inventory management
- Compare-at pricing
- Collection management
- Metafields
- Multi image upload
- Drag & drop media handling
- Product status management

## Tech Stack

- Remix
- React
- Shopify Polaris
- Shopify Admin GraphQL API
- Node.js
